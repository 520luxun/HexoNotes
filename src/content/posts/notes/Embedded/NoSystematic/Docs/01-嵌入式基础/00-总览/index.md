# 嵌入式基础 · 分区总览

> **这是什么**
> 嵌入式的地基，按「**语言 → 硬件 → 系统 → 多媒体**」四条线拆成四个知识体系。
> 每一篇都遵循同一写法：**是什么 → 为什么 → 嵌入式里怎么用 → 坑在哪**。

## 体系地图

| 体系 | 篇数 | 关键词 | 入口 |
|---|:--:|---|---|
| C 语言底层 | 8 | 运算符、指针、结构体对齐、字节序、宏、C/C++ 混编 | C语言底层总览 |
| 硬件与体系结构 | 5 | 嵌入式概论、处理器、GPU/NPU、存储器、汇编与流水线 | 硬件与体系结构总览 |
| Linux 系统 | 4 | Shell、命令速查、文件类型与 IO、IPC 与线程同步 | Linux系统总览 |
| 音视频与多媒体 | 2 | PNG/JPEG、MPEG/H.26x、PCM、回声消除 | 音视频与多媒体总览 |

## 建议顺序

1. **先有全景**：[嵌入式系统概论](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/硬件与体系结构知识体系/嵌入式系统概论/) → [处理器类型与架构](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/硬件与体系结构知识体系/处理器类型与架构/)，知道 MCU / MPU / SoC 的分工。
2. **再补语言底层**：[C语言运算符与优先级](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/C语言底层知识体系/c语言运算符与优先级/) → [指针大小与NULL](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/C语言底层知识体系/指针大小与null/) → [结构体与内存对齐](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/C语言底层知识体系/结构体与内存对齐/) → [大小端与字节序](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/C语言底层知识体系/大小端与字节序/)。
3. **理解执行**：[存储器与内存](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/硬件与体系结构知识体系/存储器与内存/) → [汇编与流水线](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/硬件与体系结构知识体系/汇编与流水线/)，把「代码怎么跑起来」串成一条线。
4. **进入系统层**：Linux系统总览，从命令、文件到进程与线程。
5. **按需扩展**：音视频与多媒体总览（编解码与通信）、[GPU与NPU](../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/硬件与体系结构知识体系/gpu与npu/)（AI 加速）。
