# 音视频与多媒体 · 知识体系总览

> **这是什么**
> 嵌入式里的「看得见、听得着」：**图像压缩 → 视频压缩 → 音频采样 → 传输与回声处理**。
> 两篇笔记共同回答一个问题：**为什么原始数据那么大，工程上是怎么把它压小、又怎么在链路上保住质量。**

## 笔记地图

| 笔记 | 一句话 | 关键概念 |
|---|---|---|
| [图像与视频压缩](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/图像与视频压缩/) | 图像格式（PNG/JPEG/BMP）、MPEG/H.26x 帧类型、YUV、3D | DCT、I/P/B 帧、色彩空间 |
| [音频基础与通信](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/音频基础与通信/) | PCM 三要素、常见编码、音视频同步、AEC、双绞线抗干扰 | 采样率、位深、G.711、Opus |

## 一条主线

```
原始信号 ──采样──> PCM / RGB ──冗余消除──> 有损/无损编码 ──封装──> 传输
              │                      │
              │                      ├─ 空间冗余：DCT + 量化（JPEG、帧内）
              │                      ├─ 时间冗余：I/P/B 帧（MPEG、H.26x）
              │                      └─ 感知冗余：心理声学（MP3、Opus）、色度采样（YUV 4:2:0）
              └─ 同步：宁可视频模糊，不可音频卡顿
```

## 建议顺序

1. **图像**：[图像与视频压缩](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/图像与视频压缩/) —— 先懂 PNG/JPEG 在压什么。
2. **视频**：[图像与视频压缩](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/图像与视频压缩/) —— 再看帧间预测怎么再省一个数量级。
3. **音频**：[音频基础与通信](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/音频基础与通信/) —— 采样率、位深、声道决定音质与带宽。
4. **链路问题**：[音频基础与通信](../../../../../../Embedded/NoSystematic/Docs/01-嵌入式基础/音视频与多媒体知识体系/音频基础与通信/) —— 回声、噪声、AEC 是通话质量的关键。
