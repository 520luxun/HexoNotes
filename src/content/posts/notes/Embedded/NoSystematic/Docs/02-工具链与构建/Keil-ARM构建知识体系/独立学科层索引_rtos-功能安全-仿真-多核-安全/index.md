# 独立学科层索引

> **定位**
> 相邻专题第 15 项正式版，但**刻意写成索引**：以下每个方向都足以独立成书，这里只给“它是什么、与构建/调试的交界、深入入口”，不假装覆盖。

## 1. RTOS 原理

| 主题 | 要点 |
|---|---|
| 调度 | 抢占式优先级、同优先级时间片、就绪队列 |
| 同步 | 互斥量、信号量、事件组、优先级继承 |
| 栈 | 每任务独立栈，需要水位测量（8.9） |
| 时间 | tick、tickless 低功耗、软件定时器 |
| 常见坑 | 中断里调用阻塞 API、优先级反转、栈溢出 |

与构建的交界：任务栈大小会影响 RAM 布局与 scatter；`FreeRTOSConfig.h` 决定裁剪。

## 2. 功能安全

| 标准 | 等级 | 关注点 |
|---|---|---|
| ISO 26262 | ASIL A–D | 汽车电子，工具置信度（TCL） |
| IEC 61508 | SIL 1–4 | 工业安全 |
| IEC 62304 | Class A–C | 医疗器械 |

- **编译器鉴定**：需要工具资质证据（版本、已知缺陷、使用约束）；
- **覆盖率**：语句/分支/MC-DC；
- **过程证据**：需求追溯、评审记录、偏离管理。

## 3. 仿真：QEMU 与 FVP

```bash
# Cortex-M3 示例（Arm MPS2 平台）
qemu-system-arm -M mps2-an385 -kernel firmware.elf -nographic
```

- 适合：纯逻辑验证、CI 中跑单元测试、无板调试；
- 不足：外设模型有限、时序不真实、低功耗与模拟外设不准；
- Arm FVP 提供更接近真实的模型（需授权）。

## 4. 多核异构

| 主题 | 要点 |
|---|---|
| 核间通信 | 共享内存 + 硬件信号量（如 HSEM）、Mailbox、IPC |
| 启动 | 主核加载从核固件、核间同步 |
| 缓存一致性 | M7 有 cache，共享区需维护/绕过 |
| 调试 | 多核同时 halt、核间断点 |

## 5. 工具链对比

| 工具链 | 前端 | 现状 | 特点 |
|---|---|---|---|
| AC5 | EDG | 停止维护 | 老工程多，汇编语法旧 |
| AC6 | LLVM/Clang | 主推 | 优化好、C11/C++17、`-Oz` |
| GCC | GCC | 活跃 | 免费、生态广、需自己配链接脚本 |
| IAR | 自有 | 商业 | 体积/速度优化强、调试器集成好 |

迁移时重点核对：ABI、启动文件、内联汇编、`#pragma`、库函数行为。

## 6. 固件安全

| 机制 | 说明 |
|---|---|
| 读保护 | RDP 0/1/2（见存储与内存映射） |
| 安全启动 | 签名 + 哈希 + 版本回滚保护 |
| 调试认证 | 量产关闭调试口，或需密钥解锁 |
| 固件加密 | XIP 解密、密钥存 OTP/安全区 |
| 防克隆 | 唯一 ID 绑定、外设指纹 |

## 7. 如何继续深入

- 每个方向先立**一个可运行的最小例**（RTOS 双任务、QEMU 跑通、双核 mailbox）；
- 再补**失败案例**（优先级反转、栈溢出、签名失败）；
- 最后才读规范原文，避免“只背概念”。
