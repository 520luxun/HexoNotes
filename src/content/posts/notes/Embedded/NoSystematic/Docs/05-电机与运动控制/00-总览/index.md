## 阅读顺序

1. **建立框架**：第 1–2 章，先分清电机、马达、舵机、伺服、减速电机、编码器的从属关系。
2. **按类型深入**：第 3–4 章，九维分类 + 常见类型逐一拆解。
3. **闭环与选型**：第 5–9 章，传感器 → 控制 → 选型方法论。
4. **实战专题**：第 7–8 章，42 步进闭环改造、370 系列对比。

> **数据可信度**
> 文中标注 **[对话结论] / [工程补充] / [待核实]** 三档；所有具体型号参数都是典型值，
> 采购前必须以规格书为准。
