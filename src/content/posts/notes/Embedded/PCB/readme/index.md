## PCB 设计要点速查

| 要点 | 说明 |
|------|------|
| **走线宽度** | 信号线 10mil 起步，电源线按电流计算（1A ≈ 40mil @1oz铜厚） |
| **过孔** | 信号过孔内径 12mil / 外径 24mil，电源过孔适当加大 |
| **去耦电容** | IC 电源引脚附近放置 0.1μF + 10μF 组合，越近越好 |
| **铺铜** | 大面积 GND 铺铜，减少地回路面积，提高抗干扰能力 |
| **差分走线** | USB/以太网等差分信号等长、等间距、紧耦合走线 |
| **丝印** | 元件位号清晰，方向一致，不覆盖焊盘 |
| **3W 原则** | 相邻走线中心距 ≥ 3 倍线宽，减少串扰 |
| **回路面积** | 信号回路面积尽量小，高速信号下方保证完整参考地平面 |
