# Expand 扩展资料目录说明

本文说明 `D:\ObsidianFirstNotes\Embedded\PCB\assets\Expand` 目录中各类文件的用途、位置和推荐使用方式。这里是对原始课程笔记的扩展区域，主要存放整理后的 Markdown 文档、示意图、动画、仿真文件和历史归档。

## 1. 目录总览

```text
Expand
├─ Docs
│  ├─ 硬件基础知识索引.md
│  ├─ 零基础
│  └─ 进阶
├─ Animations
├─ diagrams
├─ Photo
├─ Simulation
├─ Archive
└─ AGENTS.md
```

| 目录 | 主要用途 | 当前内容 |
| --- | --- | --- |
| `Docs/` | 正式学习文档和文档索引 | 1 个总索引，2 个分层目录 |
| `Docs/零基础/` | 第一次学习时建立直觉 | 3 篇入门文档 |
| `Docs/进阶/` | 公式、仿真和工程分析 | 7 篇进阶文档 |
| `Animations/` | 可直接插入笔记的 GIF 动画 | 2 个 GIF |
| `diagrams/` | 整理绘制的通用电路图 | 11 个 SVG |
| `Photo/` | 当前正式引用的截图 | 18 个 PNG |
| `Simulation/` | 可在浏览器打开的交互式仿真 | 1 个 HTML |
| `Archive/` | 原始文件、重复资源和被替代产物 | 历史资料，不作为首选入口 |

## 2. 正式文档入口

总索引位于：[硬件基础知识索引](../../../../../Embedded/PCB/assets/Expand/Docs/硬件基础知识索引/)。

它负责说明推荐学习顺序、文档之间的关系、已经合并的内容以及归档规则。第一次进入这个目录时，建议先打开总索引，不要直接从文件名猜测学习顺序。

## 3. 零基础目录

零基础文档位于 `Docs/零基础/`，目标是先建立“元件做什么、波形为什么变化”的直觉，不要求一开始就掌握复数、相量或完整传递函数。

### 3.1 电感与 RL、LC 滤波

文档：[零基础/电感与RL、LC滤波-零基础入门](../../../../../Embedded/PCB/assets/Expand/Docs/零基础/电感与rl_lc滤波-零基础入门/)

主要内容：

- 电感储能和电流惯性；
- 感抗 `XL=2πfL`；
- RL 低通和高通的判断方法；
- 截止频率 `fc=R/(2πL)`；
- LC 低通为什么能更快衰减高频；
- 电感 DCR、饱和电流和自谐振频率。

### 3.2 LC 谐振与 Q 值

文档：[零基础/LC谐振与Q值-零基础入门](../../../../../Embedded/PCB/assets/Expand/Docs/零基础/lc谐振与q值-零基础入门/)

主要内容：

- 电容和电感如何互相交换能量；
- 固有频率 `f0=1/(2π√LC)`；
- 串联谐振和并联谐振；
- Q 值、阻尼和振铃；
- `f0`、谐振峰和截止频率的区别；
- `L=10uH、C=1uF` 的完整数值示例。

### 3.3 偏置、截止频率与振荡

文档：[零基础/偏置、截止频率与振荡-零基础概念](../../../../../Embedded/PCB/assets/Expand/Docs/零基础/偏置_截止频率与振荡-零基础概念/)

主要内容：

- 直流偏置和静态工作点；
- 截止频率的含义；
- 固有频率、谐振和振铃；
- 自由响应、受迫响应和振荡器；
- 从示波器现象反推可能的电路问题。

## 5. 图片、动画与仿真资源

### 5.1 `diagrams/`：通用示意图

这里保存为文档重新绘制的 SVG 图，适合在不同笔记中重复引用。文件名按电路或现象命名，例如：

- `rlc-frequency-response.svg`：RLC 频率响应；

这里保存当前文档正在使用的 18 个 PNG 截图，主要来自电路仿真和波形记录。正式文档应优先引用 `Photo/` 中不带导出时间后缀的文件。

带 `-1777390267149-数字` 后缀的同内容副本已经移动到 `Archive/Photo-duplicates/`，用于追溯，不建议在新文档中继续引用。

## 7. Archive 归档规则

`Archive/` 中的内容不会作为推荐学习入口，但暂时保留以便追溯。

| 子目录 | 内容 | 处理原则 |
| --- | --- | --- |
| `Docs-original/` | 原始 Markdown 笔记 | 不直接修改，用于对照正式整理版 |
| `Photo-duplicates/` | 重复截图 | 不在新文档中引用，需要时再恢复 |
| `superseded/` | 被视频片段替代的旧 GIF、视频源和生成脚本 | 仅作历史记录，不作为当前资源 |

## 8. 推荐使用流程

1. 先打开 [硬件基础知识索引](../../../../../Embedded/PCB/assets/Expand/Docs/硬件基础知识索引/)。
2. 从 `Docs/零基础/` 开始，先理解元件和波形的直觉。
3. 遇到公式推导、仿真曲线或工程参数，再进入 `Docs/进阶/`。
4. 需要直观观察时，打开 `Animations/`、`diagrams/` 或 `Simulation/` 中的资源。
5. 需要核对历史内容时，再查看 `Archive/`，不要把归档文件当成当前正式结论。

## 9. 维护约定

- 新的学习文档放入 `Docs/零基础/` 或 `Docs/进阶/`，不要直接散落在 `Docs` 根目录；
- `Docs` 根目录只保留总索引和本目录说明；
- 新图片按“正式引用”与“历史备份”分别放入 `Photo/` 和 `Archive/Photo-duplicates/`；
- 文档改名后同步更新 Wiki 链接；
- 删除前先确认没有文档引用，并优先移动到 `Archive/` 而不是直接永久删除；
- 保留原始视频时间范围和来源链接，确保媒体资源可以追溯。
