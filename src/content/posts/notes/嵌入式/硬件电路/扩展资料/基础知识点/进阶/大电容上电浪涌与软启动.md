# 大电容上电浪涌与软启动

## 背景：这堂课讲了什么

在《电容两端电压不能突变》那节课里，老师分析了电容在开关闭合瞬间的电压波形，并引出一个实战问题：

> **电源输入端口并联大电容时，上电瞬间等于把电源短路，会产生巨大的浪涌电流。因此需要在开关与电容之间串入 NTC 热敏电阻或电感来抑制。**

本笔记详细展开这部分内容。

## 1. 为什么"大电容上电 = 瞬间短路"

依据电容的等效思想：

> **当电容两端电压 Vc = 0 时，可以把电容看成一根导线（短路）。**

上电前大电容没充电，Vc = 0。开关闭合的瞬间，电容就是一根导线，直接把电源正极和 GND 短路。

### 数学本质

电容充电电流：$I(t) = \frac{V}{R} \cdot e^{-t/RC}$

峰值出现在 t = 0 时刻：$I_{\text{peak}} = \frac{V}{R}$

其中 R 是回路上所有串联电阻之和：开关内阻 + 走线电阻 + 电源内阻 + 电容 ESR。

**具体算一笔账**：12V 电源、回路总电阻只有 10mΩ：$I_{\text{peak}} = \frac{12\text{V}}{0.01\Omega} = 1200\text{A}$

视频里的仿真正是在理想条件下出现了约 1200A 的电流尖峰。实际中电缆电感、电源内阻、电容 ESR 会把它压低到几十到几百安，但相对正常工作电流（几安到几十安）仍是几十到上百倍的冲击。

## 2. 浪涌电流会带来什么后果

| 后果 | 说明 |
| --- | --- |
| 电源保护/宕机 | 电流瞬间超过过流保护（OCP）阈值，电源进入保护状态或重新启动，表现为"一上电就没输出" |
| 器件损伤 | 保险丝按 I²t 熔断，浪涌足以炸保险、烧蚀开关触点、冲击整流桥与电解电容 |
| 电磁干扰（EMI） | di/dt 极大，在线缆和地线上感应高压尖峰并向外辐射；地线被顶起（地弹）会干扰共用该地的电路 |
| 电容应力 | 超出电解电容额定纹波/浪涌电流，加速老化甚至失效 |

## 3. 方案一：NTC 热敏电阻

### 原理
NTC（负温度系数）阻值随温度升高而**下降**：
- 上电瞬间：NTC 还是冷的，阻值大（例如 10Ω）→ 限制峰值电流
- 通电后：流过 NTC 的电流让它自发热 → 阻值降到很低（0.1~0.5Ω）→ 稳态损耗小

### 数值例子
12V、冷态 10Ω：$I_{\text{peak}} = \frac{12\text{V}}{10\Omega} \approx 1.2\text{A}$

### 优点
- 便宜、体积小
- 纯被动器件，无需控制电路
- 插上就有效，设计简单

### 缺点
- **断电后需要冷却时间**：刚断电几秒就重新上电，NTC 还是热的、阻值小，浪涌保护失效——这是最典型的坑
- **稳态有功耗**：热态 0.1Ω 过 10A 就有 10W 损耗、1V 压降，大电流连续工作不划算
- **受环境温度影响**：高温环境下冷态阻值本来就小，保护效果打折

### 适用场景
小到中功率（几十瓦以内）、上电频率不高的场合，如充电器、电源适配器输入防浪涌。

## 4. 方案二：电感

### 原理
电感与电容相反——**电感电流不能突变**。上电瞬间电流以固定斜率爬升：$\frac{di}{dt} = \frac{V}{L}$
理想 LC 电路峰值电流：$I_{\text{peak}} \approx V \sqrt{\frac{C}{L}}$

### 数值例子
12V、输入电容 1mF、串 1mH 电感：$I_{\text{peak}} = 12 \times \sqrt{\frac{0.001}{0.001}} = 12\text{A}$与"裸奔"时的 1200A 相比小了两个数量级。

### 优点
- 稳态对直流几乎无损耗（只吃交流/纹波）
- 适合大电流连续工作
- 顺带与电容组成 LC 滤波，改善电源质量

### 缺点
- 体积大、成本高
- LC 组合容易谐振，产生振铃和电压过冲，通常需要阻尼
- 电感饱和后限流能力失效

## 5. 方案三：其他常见软启动方式

### 预充电阻 + 继电器/接触器旁路
上电先通过大电阻缓慢给电容充电（限流到 1~2A），几百毫秒后继电器闭合把电阻短路掉。
- 优点：稳态零损耗，能扛大电流
- 缺点：机械触点、体积大
- 典型应用：电机驱动器、变频器的大电容大电流输入

### MOSFET 软启动 / 热插拔控制器
用控制芯片驱动 MOS 管缓慢打开，电流按斜坡上升（如从 0 匀速升到额定值）。
- 优点：可控、无机械件、可反复快速上电
- 典型应用：服务器电源、热插拔板卡

### 电源芯片自带软启动
很多电源芯片有软启动引脚，外接电容决定输出电压上升斜率，从源头减小冲击。

## 6. 选型对照表

| 场景 | 推荐方案 | 理由 |
| --- | --- | --- |
| 小功率适配器、充电器（几瓦~几十瓦） | NTC 或预充电阻 | 便宜简单，稳态损耗可接受 |
| 电机驱动、变频器（大电容、大电流） | 预充电阻 + 继电器旁路 | 稳态零损耗，扛大电流 |
| 服务器、热插拔板卡（频繁插拔） | MOSFET 软启动 | 可控、可反复上电，无 NTC 冷却问题 |
| 对 EMI 与效率同时敏感 | 电感 + 阻尼 / 主动软启动 | 电流平滑、稳态几乎无损耗 |

## 7. 一句话总结
> 浪涌电流的本质是 I = V/R，而 R 趋近于 0。NTC、电感、预充电阻、MOSFET 软启动做的是同一件事：**上电瞬间人为增大串联阻抗把电流限住，启动完成后再把这个阻抗消除。**
