# 博客使用手册

## 一、日常怎么用（最短路径）

在 Obsidian 里正常写笔记，写完执行一条命令：

```bash
pnpm push:all
```

- 推 GitHub → GitHub Pages 自动重建（约 1 分钟）
- 推 Gitee 源码镜像
- Cloudflare Pages 也会监听 `main` 分支自动重建（约 3 分钟）

不需要手动 `build`，不需要上传文件，也不需要打开任何控制台。

## 二、博客的四个页面

| 页面 | 地址 | 用途 |
|---|---|---|
| 首页 | `/` | 按章节顺序翻页浏览，卡片式 |
| 归档 | `/archive/` | 按年份、日期倒序，找「最近写了什么」 |
| 总目录 | `/catalog/` | 按分类分组、可折叠，适合从头系统学习 |
| 关于 | `/about/` | 个人介绍 |

右上角放大镜是站内搜索（Pagefind），支持中文。

## 三、写笔记的规则

1. **默认全部发布**：`D:\ObsidianFirstNotes` 里除剪藏/日记/工具目录外都会被同步
2. **想发剪藏**：在那篇笔记 frontmatter 加一行 `publish: true`
3. **标题**：博客直接取**文件名**（去掉日期前缀和 `.md`），所以文件名就是标题，别起太长
4. **分类**：自动取源库第二层目录名（`Embedded/FreeRTOS` → FreeRTOS），映射表在 `notes-sync.config.json` 的 `categoryMap`
5. **图片**：`![[]]`、`![]()`、`<img>` 都支持；外链图自动下载到本地；找不到的图会被丢弃而不是留破图
6. **双链**：`[[笔记名]]` 自动变成站内链接，找不到目标时降级为纯文字

## 四、常改的配置在哪

| 想改什么 | 文件 |
|---|---|
| 站点标题、副标题、头像、横幅、社交图标 | `src/config.ts` |
| 分类中文映射、发布范围、排除目录 | `notes-sync.config.json` |
| 站点地址、路径 | `astro.config.mjs`（或 `DEPLOY_SITE` / `DEPLOY_BASE` 环境变量） |

## 五、关于那个 Obsidian 图标

### 它是怎么工作的

头像下方第四个图标指向：

```
obsidian://open?vault=Embedded
```

`obsidian://` 是**操作系统级的协议**，由电脑上安装的 Obsidian 注册。浏览器点击时会把请求交给本机 Obsidian，Obsidian 再用库名 `Embedded` 找到 `D:\ObsidianFirstNotes\Embedded` 并打开。

### 别人点了会怎样

- **没装 Obsidian**：浏览器弹「此协议无法打开」或完全没反应
- **装了但库名不叫 Embedded**：Obsidian 报「找不到库」
- **装了且同名库**：会打开他自己的库（不是你的）

所以这个链接**只对你自己这台电脑有意义**，对访客相当于一个死按钮。

### 会不会泄露隐私

URL 里只有库名 `Embedded`，不包含磁盘路径、账号、内容。访客最多看到「这人用 Obsidian」。真正暴露的只是「库名」这一个词。

### 建议

- 自己用没问题，当快捷入口很顺手
- 如果在意访客体验，可以把它换成「关于」页的链接，或加个 `title` 提示「仅本机可用」
- 想彻底隐藏，删掉 `src/config.ts` 里那条 `name: "Obsidian"` 的配置即可

## 六、常见问题

**图片不显示**
1. 先强刷 `Ctrl+F5`（Cloudflare 缓存）
2. 打开 `pnpm audit:site` 看是否有 404
3. 检查源笔记里图片路径，脚本会按「笔记目录 → 父目录附件夹 → 全库唯一同名」顺序找

**分类不对**
改 `notes-sync.config.json` 的 `categoryMap`，重新 `pnpm push:all`

**构建失败**
CI 失败时会把日志推到 `ci-logs` 分支（Cloudflare 侧直接看构建日志页），常见原因是图片缺失或文件名大小写

**文章顺序乱**
- 首页/上下篇按源库目录顺序（`order` 字段）
- 归档按日期
- 总目录按标题里的章节号
三条规则不同，属于设计而非 bug

## 七、命令速查

```bash
pnpm dev                 # 本地预览（会自动同步笔记）
pnpm push:all            # 推 GitHub + Gitee，自动部署
pnpm sync-notes:preview  # 看会同步哪些笔记，不写文件
pnpm audit:site          # 全站链接/图片体检
pnpm build:domain        # 按自定义域名根路径构建（备用）
```
