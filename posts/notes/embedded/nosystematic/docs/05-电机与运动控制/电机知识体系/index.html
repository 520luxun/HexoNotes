0.2 文档地图#

0.3 三层认知模型（全文的组织逻辑）#

理解电机领域的混乱，根源在于把三个不同层级的东西放在一起比较。本文始终按下面三层来组织：

  • 元件层回答“靠什么物理效应工作”（霍尔效应、电磁感应、磁阻效应、逆压电效应）。
  • 器件层回答“这个部件能单独买、单独换吗”（电机、编码器、减速器、驱动器）。
  • 系统层回答“它是不是一个已经封装好的完整方案”（舵机 = 电机 + 减速 + 反馈 + 驱动；闭环步进 = 步进 + 编码器 + 闭环驱动器）。

大量混淆都来自层级错位：把“编码器”和“电机”并列（一个是器件、一个是另一类器件）、把“舵机”和“无刷电机”并列（一个是系统、一个是器件）、把“霍尔传感器”说成“编码器”（一个是元件、一个是器件）。

1. 全景速览#

1.1 一句话版本#

电机（马达）是总称；直流/交流是按电源分，同步/异步/直流是按原理分，驱动/控制是按用途分；无刷是直流的技术分支，步进与伺服是控制电机的两大代表；舵机是“电机+减速+反馈+驱动”的集成系统，减速电机是“电机+减速器”的组合，编码器是反馈传感器而不是电机；所谓“闭环”，本质是给执行器补上“眼睛（编码器）+ 大脑（控制器）”。

1.2 十二条核心结论#

  1. “电机”是总称，“马达（Motor）”是俗称，二者基本同义；日常语境里的“电机”绝大多数指电动机（电能→机械能），与之并列的是发电机（机械能→电能）。[对话结论]
  2. 这些词不在同一层级：无刷电机 ⊂ 直流电机；步进、伺服 ⊂ 控制电机；舵机是成品系统；减速电机是组合体；编码器是传感器。[对话结论]
  3. 电机没有唯一“完美”分类法，必须多维度交叉看：同一台“三相异步防爆电机”同时体现了电源（交流三相）、原理（异步）、用途（驱动）、环境（防爆）四个属性。[对话结论]
  4. 42 步进“带磁柱”≠ 闭环。磁柱只是尾部预留的磁铁安装位，真正闭环还需要：径向磁铁 + 磁编码器芯片 + 闭环驱动器/控制器。[对话结论]
  5. “众灵 370”大概率是标准 370 有刷直流电机；众灵更像机器人开发/套件/控制方案品牌或社区，而非电机原厂。[对话结论][待核实]
  6. MG370 不是严格标准型号，更像“带编码器接口的 370 减速电机平台”，常见于轮趣科技等创客品牌；分霍尔版与 GMR 版，且存在“有刷/无刷”口径冲突，买前必须确认。[对话结论][待核实]
  7. MG310 定位轻负载高精度：扭矩约 0.4 kgf·cm、连续电流约 1100 mA，动力弱于 MG370，但 GMR 版定位精度高、响应快。[对话结论]
  8. 霍尔传感器是元件，编码器是器件/功能类别。霍尔可以做编码器（霍尔编码器），但编码器还可以是光电、GMR/TMR、电容、感应、旋变等。[对话结论]
  9. “霍尔版 / GMR 版”都是磁编码器，但分辨率差几个数量级：13 线磁环只能做速度闭环，500 线 GMR 才能做像样的位置闭环。[对话结论]
  10. 闭环三要素 = 执行器 + 反馈传感器 + 控制器/驱动器；PID 的作用是根据“目标 − 反馈”的偏差动态修正输出。[工程补充]
  11. 加编码器不会提升扭矩和最高转速，它解决的是“丢步、精度、稳定性”，不是“更有劲”。[对话结论]
  12. 选型的本质是权衡：负载（扭矩）× 速度（转速）× 精度（反馈分辨率）× 体积重量 × 成本 × 控制器能力，六个变量里最多同时满足四个。[工程补充]

2.4 六个高频混淆点逐一拆解#

混淆点 1：电机 = 马达？#

基本等同，但语体不同：

  • “电机”偏书面/工程/铭牌用语（如“三相异步电动机”）；
  • “马达”偏口语/港台/消费电子用语（如“振动马达”“马达驱动”）；
  • 严格讲“电机”是总称，包含发电机；而“马达（Motor）”在英文里也只指电动机，不包括 Generator。

所以：“电机”⊃“马达”，日常可互换，但写技术文档时“发电机”不能叫“马达”。

混淆点 2：直流电机 vs 无刷电机#

包含关系，不是并列关系：

  • 有刷：结构简单、便宜、低速扭矩好，但电刷磨损、火花、噪声、寿命受限。
  • 无刷：效率高、寿命长、噪声低、可高速，但必须配电调/驱动器，成本高，控制复杂。

混淆点 3：无刷电机 vs 永磁同步电机（PMSM）#

工程上经常混用，严格区分看两点：

维度BLDC（方波无刷）PMSM（永磁同步）
反电动势波形梯形波正弦波
驱动电流方波/六步换向正弦波（FOC/SVPWM）
位置反馈三霍尔即可编码器/旋变，或无感观测
转矩脉动较大小，运行平稳
典型场景风机、水泵、电动工具、航模伺服、电动汽车、精密传动

日常口语里“无刷电机”常泛指两者；买伺服时看到“交流伺服”，其本体基本就是 PMSM + 高分辨率编码器。[工程补充]

混淆点 4：步进 vs 伺服#

维度步进电机伺服电机
控制方式开环（可加编码器变闭环）闭环（天生带反馈）
反馈通常无编码器/旋变，分辨率高
过载能力弱，过载直接失步强，可短时过载 2–3 倍
低速平稳性有低频共振，需细分/阻尼好
高速性能扭矩随转速快速下降恒扭矩区宽，弱磁可扩速
成本低高（电机+驱动器+编码器）
调试难度低（给脉冲就行）高（需整定 PID、惯量匹配）
典型场景3D 打印机、雕刻机、点胶机机械臂、CNC、AGV 转向

混淆点 5：舵机 vs 伺服#

  • 舵机是“成品伺服系统”：内部 = 直流电机 + 减速齿轮组 + 电位器/磁编码器 + 控制电路，输入 PWM，输出角度。
  • 工业伺服是“器件级产品”：伺服驱动器 + 伺服电机 + 编码器分开卖，输入指令（脉冲/总线），输出力矩/位置。
  • 二者原理同源（闭环位置控制），差别在集成度、功率、精度、接口、成本。

混淆点 6：编码器 vs 霍尔传感器#

  • 霍尔传感器：把磁场变成电信号的元件，输出是“有/无磁场”或“磁场强度电压”。
  • 编码器：把运动变成可直接使用的数字量的器件，内部已包含“传感元件 + 信号处理（放大、比较、计数、细分、接口）”。
  • 因此“霍尔传感器可替代编码器”这句话只在功能层面成立（线性霍尔 + 控制器做角度解算），元件层面不成立。[对话结论]

3. 市面电机的九维分类体系#

3.1 为什么没有“唯一正确”的分类#

同一台电机可以同时被贴很多标签：

一台用在化工泵上的 三相异步防爆电机，同时属于： 交流电机（电源）· 异步/感应电机（原理）· 驱动电机（用途）· 低速大扭矩（速度取向）· 鼠笼转子（结构）· 防爆型（环境）· 中型（功率）。

所以正确姿势不是找“唯一分类”，而是用九个维度去“投影”一台电机，每个维度回答一个问题。

3.4 维度二：按电磁原理#

这是最“硬核”的分类维度，决定了电机的运行特性。

3.4.1 同步电机#

  • 定义：转子转速与定子旋转磁场严格同步，转差率 s = 0。
  • 转速公式：n = 60f / p（f 为频率 Hz，p 为极对数）。
  • 特点：效率高、功率因数可调（电励磁）、转速恒定不随负载变化。
  • 细分：
    • 永磁同步（PMSM）：转子用永磁体，效率最高，是现代伺服与新能源车主力。
    • 电励磁同步：转子绕组通直流励磁，可调功率因数，用于大型发电。
    • 磁阻同步：靠转子凸极的磁阻差异产生转矩，结构坚固。
    • 开关磁阻（SRM）：双凸极结构，无永磁体、耐高温、容错强，但转矩脉动大、噪声大。
    • 磁滞同步：小功率、恒速场合（如计时器）。

3.4.2 异步电机（感应电机）#

  • 定义：转子转速略低于同步转速，存在转差率 s = (n1 − n)/n1，靠转子感应电流与气隙磁场作用产生转矩。
  • 特点：结构简单、无电刷、极其耐用、成本低，是工业用电的绝对主力（约占工业电机 80% 以上）。
  • 细分：
    • 鼠笼式：转子为铸铝/铜条笼，最通用。
    • 绕线式：转子绕组可外接电阻，启动转矩大、可调速，用于起重机、轧机。
    • 双馈式：转子也接电网，用于风力发电。

3.4.3 直流电机（换向类）#

  • 有刷：电刷 + 换向器机械换向，转矩大、控制简单（调压调速），但需维护。
  • 无刷：逆变桥 + 转子位置信息电子换向，寿命长、效率高。
  • 励磁方式（有刷）：串励（启动转矩大）、并励（转速稳）、复励（兼顾）、永磁（小功率主流）。

3.4.4 步进与磁阻类#

  • 步进电机严格说属于同步电机的一种特殊运行方式（转子跟随定子磁场步进），但工程上单独成类。
  • 细分见 4.5 步进电机。

3.4.5 非电磁原理#

  • 压电/超声波电机：逆压电效应 + 摩擦驱动，低速大扭矩、断电自锁、无电磁干扰。
  • 静电电机：MEMS 微执行器。
  • 形状记忆合金：特殊场景，效率低。

3.5 维度三：按用途#

类别目标核心指标代表
驱动电机把电能变成“干活的力量”效率、功率密度、可靠性、成本电动工具、家电、风机水泵、电动车
控制电机把电能变成“听指令的动作”精度、响应、线性度、可控性步进、伺服、力矩电机
信号电机把机械量变成电信号精度、线性度、分辨率旋转变压器、测速发电机、自整角机

用途维度是选型第一问**** “这台电机是要出力，还是要听话？”——出力看效率与扭矩，听话看反馈与控制。舵机之所以贵，是因为它同时要“听话”。

3.7 维度五：按结构与转子形式#

  • 集中绕组 vs 分布绕组：集中绕组工艺简单、端部短；分布绕组反电动势更正弦、转矩脉动小。

4. 常见电机类型逐一拆解#

本章对每一类电机按统一模板展开：结构 → 原理 → 优点/缺点 → 典型参数 → 驱动方式 → 应用 → 选型要点。参数均为典型量级，具体型号以规格书为准。

4.1 有刷直流电机（Brushed DC）#

结构#

原理#

电流经电刷进入换向器，换向器随转子旋转周期性改变电枢电流方向，保证同一磁极下的导体电流方向不变，从而产生单向持续转矩。

优缺点#

优点缺点
结构简单、成本最低电刷磨损，寿命受限（几百至几千小时）
启动转矩大、低速性能好换向火花、电磁干扰（EMI）
调速简单（调压即可）噪声大，高速受限
驱动电路极简（H 桥即可）需定期维护，不适合洁净/防爆环境

典型参数（以 370 系列为例）#

项目典型值
外径约 24.3 mm
机身长度约 30.8 mm
电压6 V / 12 V
空载转速6 V 约 16 500 rpm；12 V 约 33 600 rpm
空载电流12 V 约 0.51 A
堵转电流可达约 20 A
堵转扭矩约 0.7 kg·cm ≈ 0.069 N·m
特点功率密度大、发热明显、非静音

堵转电流 20 A 的含义 如果驱动器只给 2 A，堵转时电压会被拉垮或直接烧驱动。选 H 桥/驱动芯片要看峰值电流，不是看空载电流。

驱动方式#

  • 单向：MOSFET 低边开关（只需调速）。
  • 双向：H 桥（L298N、TB6612、DRV8871、BTS7960）。
  • 调速：PWM（频率建议 10–20 kHz，避开音频段）。
  • 保护：续流二极管、过流检测、软启动。

选型要点#

  1. 先看堵转电流与额定电流，驱动器留 2 倍余量；
  2. 看寿命要求，长时间运行优先无刷；
  3. 需要低速大扭矩 → 加减速器（即减速电机）；
  4. 需要精确控制 → 加编码器 + 闭环驱动器。

4.2 无刷直流电机（BLDC）#

结构#

原理#

用逆变桥按转子位置依次给三相绕组通电，产生旋转磁场拖动永磁转子。换向由电子电路完成，不再有机械电刷。

有感和无感#

类型位置信息来源优点缺点场景
有感3 个霍尔（120° 电角度）低速启动可靠、成本低霍尔怕高温、布线多电动自行车、风机
无感反电动势过零/磁链观测无传感器、耐高温、线少低速启动困难、需算法水泵、无人机、压缩机
编码器型增量/绝对编码器精度最高、可位置控制成本高伺服、机器人关节

六步换向（方波驱动）#

以 120° 安装的三个霍尔为例，转子每转一个电周期有 6 个状态，每次只导通两相：

步霍尔 H1H2H3导通相电流方向
1001A→BA 高 B 低
2101A→CA 高 C 低
3100B→CB 高 C 低
4110B→AB 高 A 低
5010C→AC 高 A 低
6011C→BC 高 B 低

维度六步方波FOC 正弦

转矩脉动大（换向瞬间）小，平稳

优缺点#

优点缺点
效率高（80–90%+）必须配驱动器/电调，成本高
寿命长（无电刷）控制复杂，调试门槛高
高速性能好低速大扭矩需减速器

选型要点#

  1. Kv 值（rpm/V）决定转速：n ≈ Kv × U；
  2. Kt（N·m/A）≈ 9.55 / Kv，决定扭矩常数；
  3. 低速启动看是否有感；
  4. 需要力矩平稳 → FOC；
  5. 电调电流留 1.5–2 倍余量。

4.3 永磁同步电机（PMSM）#

  • 与 BLDC 的关系：本体结构几乎一样（永磁转子 + 三相定子），差别在反电动势波形（正弦 vs 梯形）与驱动方式（FOC vs 六步）。
  • 优势：转矩平稳、效率高、功率密度高、调速范围宽（弱磁扩速）。
  • 典型场景：交流伺服、电动汽车驱动、压缩机、精密机床。
  • 关键概念：
    • d/q 轴：Park 变换后，d 轴励磁、q 轴转矩；
    • Id = 0 控制：表贴式 PMSM 常用，单位电流最大转矩；
    • 弱磁控制：高速时注入负 Id，降低反电动势，扩展转速。

4.4 交流异步电机（感应电机）#

原理#

定子三相绕组通三相交流电产生旋转磁场，转子导体切割磁力线感应电流，感应电流与磁场作用产生转矩。转子转速永远追不上同步转速（否则无转差、无感应电流、无转矩）。

转差率 s = (n1 − n) / n1，额定负载时 s 通常 1%–5%。

分类#

类型转子特点场景
鼠笼式铸铝/铜条笼结构最简单、最耐用、最便宜风机、水泵、压缩机
绕线式三相绕组 + 滑环可外接电阻，启动转矩大、可调速起重机、轧机、球磨机
双馈式绕线 + 变频器转子也接电网，调速效率高风力发电

优缺点#

优点缺点
无电刷、极耐用效率略低于永磁同步
成本低、易维护启动转矩较小（鼠笼）
可直接接电网运行调速需变频器，低速效率下降
过载能力强功率因数滞后，需补偿

调速#

  • 变频调速（VFD）：改变频率 f 即可改变同步转速 n1 = 60f/p，是现代主流。
  • 变极调速：改变极对数，有级调速。
  • 降压调速：简单但损耗大，已少用。

4.5 步进电机：开环定位的性价比之王#

结构分类#

类型步距角特点场景
反应式 VR较大（如 7.5°）结构简单、无永磁、转矩小仪表、打印机
永磁式 PM较大（如 7.5°/15°）成本低、转矩小家电、玩具
混合式 HB1.8°/0.9°/0.72°精度高、转矩大，绝对主流3D 打印、CNC、雕刻机

工作原理#

定子绕组按脉冲序列依次通电，每来一个脉冲，转子转过一个步距角。

  • 42 步进（NEMA 17）：步距角 1.8° → 每转 200 步；
  • 57 步进（NEMA 23）：步距角 1.8° → 每转 200 步；
  • 0.9° 电机 → 每转 400 步。

细分驱动#

驱动器把“一个整步”再细分为 N 个微步（常见 2/4/8/16/32/64/128/256）：

每转脉冲数 = 360° / 步距角 × 细分

失步与共振#

  • 失步：负载扭矩 > 输出扭矩，或加速度 > 电机能力，转子跟不上磁场 → 位置永久偏差。
  • 共振：某些转速区间（尤其低速）转子振荡，表现为噪声/丢步 → 解决：细分、加阻尼、避开共振区、加减速曲线。

驱动方式#

  • 恒压驱动（L298N）：简单，低速转矩差、发热大。
  • 恒流斩波驱动（A4988、DRV8825、TMC 系列）：主流，电流可调、细分高。
  • 闭环步进：加编码器 + 闭环驱动器，见 第 7 章。

4.6 伺服电机与舵机#

4.6.1 伺服系统的构成#

  • 三环：电流环（最内，μs 级）→ 速度环（ms 级）→ 位置环（最外）。
  • 刚性：伺服的核心竞争力是“指令到位的跟随精度”，靠高分辨率编码器 + 高带宽电流环。

4.6.3 舵机（Hobby Servo）#

  • 输入：50 Hz PWM，脉宽 0.5–2.5 ms 对应 0–180°（不同型号略有差异）。
  • 内部：电位器反馈 + 比较器 + H 桥，本质是模拟位置闭环。
  • 指标：扭矩（kg·cm）、速度（s/60°）、死区、虚位。
  • 数字舵机：更高 PWM 频率（可达 300 Hz）、更高分辨率、可编程。
  • 总线舵机：串行总线（TTL/RS485），可读角度、温度、负载，适合多关节机器人。

舵机的“堵转” 舵机没有真正的过流保护（低成本型号），卡住不动会持续大电流烧电机或烧驱动。选型时扭矩留 1.5–2 倍余量。

关键关系#

  • n_out = n_in / i（i 为减速比）
  • T_out = T_in × i × η（η 为效率，0.5–0.97）
  • 减速比越大 → 转速越低、扭矩越大、背隙与惯量折算也越大。

惯量折算 负载惯量折算到电机侧要除以 i²：J_load' = J_load / i²。所以大减速比能让小电机驱动大惯量，但也降低了系统的“手感”与带宽。

4.8 直线电机#

  • 原理：把旋转电机“剖开铺平”，定子（磁轨）与动子（线圈）相对直线运动。
  • 类型：平板式、U 型槽式、圆柱式；有铁芯（推力大、有吸力）与无铁芯（无吸力、轻）。
  • 优点：无接触传动、无背隙、高加速度、高精度、长行程。
  • 缺点：贵、发热集中、需光栅/磁栅反馈、防护要求高。
  • 场景：磁悬浮、精密机床、半导体设备、3D 打印。

4.9 压电电机 / 超声波电机#

  • 原理：逆压电效应使定子产生微幅振动，通过摩擦力驱动转子/动子。
  • 优点：低速大扭矩、断电自锁、无电磁干扰、无齿轮背隙、可做到极小。
  • 缺点：寿命受摩擦材料限制、效率低、驱动电路特殊（高频高压）。
  • 场景：相机自动对焦、精密位移台、手表、医疗微型设备。

4.10 力矩电机 / 直驱电机#

  • 特点：极对数多、转速低、扭矩大，直接驱动负载，省去减速器。
  • 优点：无背隙、刚性好、响应快、安静。
  • 缺点：体积大、成本高、需高分辨率反馈。
  • 场景：转台、云台、机器人关节（协作机器人）、电梯曳引机。

5. 编码器与位置传感器体系#

5.1 先把三个词摆正#

词层级本质直接输出

5.2 霍尔传感器（Hall Sensor）#

5.2.1 原理#

电流通过半导体薄片，在垂直方向施加磁场，载流子受洛伦兹力偏转，两侧产生霍尔电压 V_H ∝ I × B。由此把磁场变成电信号。

5.2.2 三种类型#

类型输出特点典型用途
开关型高/低电平有磁场即翻转，最简单限位、接近开关、转速计数
锁存型磁场极性翻转时输出翻转需要 N/S 交替，抗抖动BLDC 换向（三霍尔）
线性型模拟电压 ∝ 磁场强度可测角度/位移角度检测、电流传感器、油门踏板

5.2.3 在 BLDC 中的角色：换向，不是测位置#

  • 三个锁存霍尔相隔 120° 电角度安装；
  • 转子每转一圈（电周期）输出 6 种组合；
  • MCU 查表决定导通哪两相 → 六步换向。

这里的霍尔只告诉控制器“现在在哪个 60° 扇区”，分辨率只有 6 个状态/电周期，不能做高精度位置控制。这是“霍尔版只能做速度闭环”的根本原因。[对话结论]

5.2.4 线性霍尔做角度#

两个线性霍尔正交放置，测 Bx、By，用 θ = atan2(By, Bx) 解算角度 → 这就是很多磁编码器芯片的内部原理（如 AS5600 一类）。

例 1：MG370 霍尔版（13 线磁环）

  • 电机轴 CPR = 13 × 4 = 52；
  • 减速比 1:34 → 输出轴 CPR = 52 × 34 ≈ 1 768；
  • 输出轴角分辨率 ≈ 360 / 1 768 ≈ 0.204°。

例 2：MG370 GMR 版（500 PPR，减速比 34.014）

  • 电机轴 CPR = 500 × 4 = 2 000；
  • 输出轴 CPR = 2 000 × 34.014 ≈ 68 028；[对话结论]
  • 输出轴角分辨率 ≈ 360 / 68 028 ≈ 0.0053°。

例 3：42 步进闭环（14 位磁编码器）

  • CPR = 2¹⁴ = 16 384；
  • 角分辨率 = 360 / 16 384 ≈ 0.022°（即对话中“理论精度约 0.02°”的来源）。[对话结论]

分辨率 ≠ 精度

  • 分辨率是“能分辨的最小变化”；
  • 精度是“测量值与真实值的偏差”；
  • 中间还隔着安装偏心、磁铁充磁不均、码盘刻线误差、传动背隙、温漂。 500 线编码器给 0.005° 分辨率，不代表系统能定位到 0.005°。

6.2 闭环三要素与信号链#

以“有刷直流 + 编码器 + PID”为例：

  1. 编码器输出 A/B 脉冲 → MCU 计数得到位置，差分得到速度；
  2. 与目标速度比较，得到误差 e = v_ref − v_actual；
  3. PID 计算输出 u；
  4. u 映射为 PWM 占空比 → H 桥 → 电机电压；
  5. 循环，直到误差趋近 0。

6.3 三环控制结构#

6.5 工程补充：让闭环“好用”的几个细节#

  1. 抗积分饱和（Anti-windup）：输出限幅时停止积分，或积分分离（误差大时不积分）。
  2. 前馈：把目标速度/加速度直接前馈到输出，减少 PID 负担（u = u_pid + Kf·v_ref）。
  3. 低通滤波：编码器差分速度噪声大，加一阶低通（截止频率取带宽的 2–5 倍）。
  4. 死区补偿：齿轮背隙、静摩擦导致的“小误差不动”，可加最小 PWM 或摩擦模型。
  5. 采样同步：编码器计数与 PWM 更新同步，避免拍频。
  6. 限流/限速：任何闭环都要有输出限幅，否则堵转即烧。

7. 专题：42 步进电机闭环改造#

7.1 结论先行#

可以闭环，但“带磁柱”本身不等于闭环。 [对话结论] “磁柱”只是尾部预留的机械安装位，为磁编码器提供“可读的目标”。真正闭环需要补齐整条链路：磁铁 → 磁编码器芯片 → 闭环驱动器/控制器。

7.2 “磁柱”到底是什么#

  • 42 步进电机（NEMA 17）尾部常见一个圆柱形凸台/孔位，业内叫“磁柱”或“磁柱孔”。
  • 作用是固定径向充磁的磁铁，让磁铁与转子同轴旋转。
  • 商家卖“带磁柱的闭环专用电机”，本质是出厂就帮你把安装位留好了，省去自己加工。[对话结论]

两个“精度”不是一回事

  • 步进分辨率（细分后每脉冲角度）决定“能命令到多细”；
  • 编码器分辨率决定“能测到多细”。 闭环系统的实际精度由两者中较差的那个 + 机械误差决定。所以“0.02° 理论精度”是编码器测量分辨率，不是整机重复定位精度。

7.6 安装要点（决定成败）#

  1. 气隙 < 2 mm：磁铁与芯片距离过大，磁场太弱，读数跳变。[对话结论]
  2. 精确对中：磁铁中心与芯片中心偏差 > 0.5 mm 就会引入周期性角度误差。
  3. 磁铁与芯片平行：倾斜会产生非线性误差。
  4. 远离干扰源：电机绕组、电源线、PWM 走线要远离芯片与信号线。
  5. PCB 固定牢：振动导致气隙变化 → 读数抖动。
  6. 信号线屏蔽/双绞：SPI 时钟线尤其容易串扰。

7.7 校准流程#

校准不能带载做 首次校准应空载，让驱动器学习“磁铁角度 ↔ 电角度”的对应关系。带载校准会把负载形变、背隙一并学进去，引入系统误差。[对话结论]

7.8 效果边界与常见误区#

误区事实
“加了编码器扭矩变大”不会。扭矩由电机与电流决定，编码器只提供反馈。[对话结论]
“闭环后不会堵转”会。扭矩不够照样堵转，只是驱动器知道并报警。
“闭环能提高最高转速”基本不能。高速受反电动势与驱动器电压限制。
“0.02° 就是整机精度”只是编码器分辨率；整机还受背隙、形变、安装误差影响。
“带磁柱就是闭环电机”磁柱只是安装位，没有芯片和闭环驱动器仍是开环。
“细分越高精度越高”细分提高平滑度与分辨率，不消除步距角误差与背隙。

10.2 二十问速答#

Q1：电机和马达到底有什么区别？ 基本同义，“电机”是总称、偏书面，“马达”是 Motor 的俗称、偏口语；严格说“电机”还包含发电机。

Q2：无刷电机是不是接上电就能转？ 不能。必须有驱动器/电调按转子位置换向。

Q3：步进电机会丢步吗？ 会。负载超扭矩、加速度过大、共振区、驱动电流不足都会丢步，且开环下无感知。

Q4：闭环步进能替代伺服吗？ 中低速、中负载可以；高动态、高速、高过载场景仍建议伺服。

Q5：编码器线数越高越好吗？ 不是。要看控制器计数能力、安装精度、传动背隙；过高分辨率在低精度机械上是浪费。

Q6：霍尔版和 GMR 版怎么选？ 只要测速/里程 → 霍尔版；要定位/锁位/低速平稳 → GMR 版。

Q7：42 步进带磁柱就能闭环吗？ 不能。“带磁柱”只是有安装位，还需磁铁、磁编码器芯片、闭环驱动器。

Q8：MG370 是有刷还是无刷？ 两种口径都有，买前必须确认；有刷与无刷驱动器不通用。

Q9：舵机和伺服有什么区别？ 舵机是集成好的位置伺服系统（PWM 输入），工业伺服是分体器件（驱动器+电机+编码器）。

Q10：减速比越大越好吗？ 不是。大减速比换扭矩，但降低转速、增加背隙与惯量折算，还可能自锁。

Q11：电机为什么发热严重？ 电流大、散热差、长时间堵转、驱动波形差、电压过高。步进恒流驱动本身就热。

Q12：PWM 频率选多少？ 有刷：10–20 kHz（避开听觉）；步进斩波：20–40 kHz；BLDC：按驱动器要求。

Q13：编码器计数跳动/丢数怎么办？ 查屏蔽与接地、加滤波、降脉冲频率、用硬件计数、查 A/B 接线与上拉。

Q14：电机反转怎么改？ 有刷：交换两根电机线；无刷：交换任意两相线或软件改相序；步进：交换一相的两根线或改方向引脚。

Q15：堵转电流为什么这么大？ 堵转时反电动势为 0，电流只受绕组电阻限制，I = U/R，所以远大于额定。

Q16：12 V 电机能接 24 V 吗？ 短时可能转得更快，但发热、电刷磨损、绝缘都会恶化，不建议长期超压。

Q17：步进电机为什么高速没劲？ 绕组电感限制电流上升速度，频率越高电流越小，扭矩随转速快速下降。

Q18：编码器需要屏蔽吗？ 需要。A/B 是高频脉冲，长线必须双绞屏蔽，屏蔽层单端接地。

Q19：失步、堵转、过冲分别是什么？ 失步：转子跟不上磁场；堵转：负载卡死、转速为 0 但通电；过冲：超调后回摆。

Q20：选型第一步该做什么？ 算负载扭矩与转速，并留 1.5–2 倍余量——其余都是在这个基础上做取舍。
