电容容抗与 RC 低通、高通滤波原理#

本文由原“容抗 Xc 原理”和“RC 低通与高通滤波电路原理”合并而成：前半部分先建立电容的频率、相位与储能直觉，后半部分再把这些结论用于 RC 低通和高通分析。

RC 滤波器只需要一颗电阻和一颗电容，就能让不同频率的信号受到不同程度的衰减。它常用于传感器信号调理、ADC 输入滤波、PWM 转模拟电压、交流耦合和去除直流偏置。

理解 RC 滤波器，关键不是死记“高频走哪里”，而是同时看清三件事：

  1. 电容容抗随频率变化；
  2. 输出电压取在电阻还是电容两端；
  3. 电阻和电容构成的是交流阻抗分压，不是普通直流电阻分压。

1. 电容容抗与复阻抗#

理想电容的容抗大小为：

XC=12πfCX_C=\frac{1}{2\pi fC}XC​=2πfC1​

其中：

  • XCX_CXC​：容抗，单位 Ω；
  • fff：信号频率，单位 Hz；
  • CCC：电容量，单位 F。

由公式可以直接得到：

  • 频率越高，XCX_CXC​ 越小；
  • 频率越低，XCX_CXC​ 越大；
  • 电容量越大，XCX_CXC​ 越小；
  • 直流稳态 f=0f=0f=0 时，理想容抗趋近无穷大。

“通高频、阻低频”描述的是相对趋势，不是绝对短路或断路。实际电流还取决于信号源、负载、串并联方式以及输出取样位置。

1.0 容抗的直觉、数值和能量#

以 C=0.1uFC=0.1\text{uF}C=0.1uF 为例：

刚接通直流电源时，电容仍会充电；只有进入稳态、两端电压不再变化后，理想直流电流才为零。真实电容还存在漏电。

电容的基本关系为：

i=CdUdti=C\frac{dU}{dt}i=CdtdU​

所以电流取决于电压的变化速度。对于正弦稳态，电容电流超前电容电压 90∘90^\circ90∘。

理想电容储存的能量为：

E=12CU2E=\frac{1}{2}CU^2E=21​CU2

理想电容在一个完整交流周期内吸收和释放能量，平均有功功率为零；真实电容则因 ESR、漏电和介质损耗而发热。

可以把电容类比为带弹性隔膜的小水箱：压力快速变化时，它不断吸入、释放流体；压力长期不变后，不再持续流动。这个类比只用于理解趋势，不能代替复阻抗计算。

其中 ω=2πf\omega=2\pi fω=2πf，jjj 表示相位信息。这项中的 −j-j−j 很重要：电容不只是改变幅值，还会让输出产生相位差。

> fff 是普通频率，表示每秒完成多少个周期，单位为 Hz；ω\omegaω 是角频率，表示每秒变化多少弧度，单位为 rad/s。两者满足 ω=2πf\omega=2\pi fω=2πf，因此代入 ZC=1/(jωC)Z_C=1/(j\omega C)ZC​=1/(jωC) 时，不能把 Hz 数值直接当作 ω\omegaω 使用。例如 1kHz1\text{kHz}1kHz 对应 ω≈6283rad/s\omega\approx6283\text{rad/s}ω≈6283rad/s。

1.1 什么是复阻抗#

直流电路使用普通电阻描述电压与电流的关系：

R=UIR=\frac{U}{I}R=IU​

对于正弦交流，电阻、电容和电感不仅会改变电流大小，还可能使电压与电流在时间上错开。为了把“阻碍大小”和“相位差”同时记录下来，需要使用复阻抗：

Z=U‾I‾Z=\frac{\underline U}{\underline I}Z=I​U​​

其中：

  • ZZZ 是复阻抗，单位仍然是 Ω；
  • U‾\underline UU​ 是包含幅值和相位的电压相量；
  • I‾\underline II​ 是包含幅值和相位的电流相量。

复阻抗的一般形式为：

Z=R+jXZ=R+jXZ=R+jX

  • RRR 是实部，表示电阻性成分，通常会消耗有功功率并发热；
  • XXX 是虚部，表示电抗性成分，反映电感、电容储存和释放能量的作用；
  • jjj 是虚数单位，满足 j2=−1j^2=-1j2=−1。电路中使用 jjj，是为了避免与电流符号 iii 混淆。

> “虚部”并不是说这部分不存在。它是一种数学记号，用来保存电压和电流的相位关系。

1.4 为什么电容复阻抗中有负号#

电容的复阻抗为：

ZC=1jωCZ_C=\frac{1}{j\omega C}ZC​=jωC1​

1j=−j\frac{1}{j}=-jj1​=−j

ZC=−jωC=−jXCZ_C=-\frac{j}{\omega C}=-jX_CZC​=−ωCj​=−jXC​

  • 电容电压滞后电容电流 90°；
  • 换一种常用说法，就是电容电流超前电容电压 90°。

电感则相反：ZL=+jXLZ_L=+jX_LZL​=+jXL​，所以电感电流滞后电感电压 90°。

∣Ztotal∣=R2+XC2|Z_{total}|=\sqrt{R^2+X_C^2}∣Ztotal​∣=R2+XC2​​

假设某个频率下：

2. RC 低通滤波器#

2.1 电路结构#

低通滤波器的连接方式是：电阻串联在信号路径中，电容从输出节点接到 GND，输出取电容两端。

图中：

  • 输入信号从 VinV_{in}Vin​ 进入；
  • R12 是串联电阻 RRR；
  • C6 是对地电容 CCC；
  • VoutV_{out}Vout​ 是电容两端的电压。

简化拓扑可以写成：

低通滤波器的作用是：

让低频信号基本通过，让高频信号逐渐衰减。

2.2 用阻抗分压理解#

低通输出取在电容两端，因此：

> 低通和高通计算中使用 ZC=1/(jωC)Z_C=1/(j\omega C)ZC​=1/(jωC)，是因为这里分析的是正弦交流稳态。由电容关系 i=C dv/dti=C\,dv/dti=Cdv/dt，在相量域中微分对应乘以 jωj\omegajω，因此 V=I/(jωC)V=I/(j\omega C)V=I/(jωC)，电容的复阻抗就是 ZC=V/I=1/(jωC)Z_C=V/I=1/(j\omega C)ZC​=V/I=1/(jωC)。只使用 XC=1/(ωC)X_C=1/(\omega C)XC​=1/(ωC) 只能得到阻抗大小，无法保留电容电压滞后电流 90∘90^\circ90∘ 的相位信息；使用 ZCZ_CZC​ 才能通过复数分压同时算出幅值和相位。分析阶跃等瞬态时，应改用时间常数、微分方程或 ZC=1/(sC)Z_C=1/(sC)ZC​=1/(sC)。

VoutVin=ZCR+ZC=11+jωRC\frac{V_{out}}{V_{in}} =\frac{Z_C}{R+Z_C} =\frac{1}{1+j\omega RC}Vin​Vout​​=R+ZC​ZC​​=1+jωRC1​

幅值比为：

∣VoutVin∣=11+(ωRC)2\left|\frac{V_{out}}{V_{in}}\right| =\frac{1}{\sqrt{1+(\omega RC)^2}}​Vin​Vout​​​=1+(ωRC)2​1​

φLP=−arctan⁡(ωRC)\varphi_{LP}=-\arctan(\omega RC)φLP​=−arctan(ωRC)

低频输入#

低频时 XCX_CXC​ 很大，电容两端分到大部分输入电压，因此：

Vout≈VinV_{out}\approx V_{in}Vout​≈Vin​

输出幅值接近输入，相位差也很小。

高频输入#

高频时 XCX_CXC​ 很小，电容两端只能分到较小电压，因此：

Vout≪VinV_{out}\ll V_{in}Vout​≪Vin​

从节点角度看，高频电流通过低阻抗电容返回 GND，输出节点的高频电压被压低。

> “高频被电容短路到地”是一种近似说法。真实电容的阻抗不是绝对 0，高频信号也不是突然完全消失，而是随频率升高连续衰减。频率非常高时，还必须考虑电容的 ESR、ESL 和自谐振频率。

2.3 不要把低通理解成“电流选择走电阻还是电容”#

在这个最简单的 RC 低通回路里，R 与 C 对交流回路而言是串联关系，流过 R 和 C 的回路电流相同。并不存在一股电流在 R 和 C 之间自由二选一。

正确理解是：

  • R 与 ZCZ_CZC​ 共同决定总阻抗和回路电流；
  • 输出取在 ZCZ_CZC​ 两端；
  • ZCZ_CZC​ 随频率改变，所以电容两端的分压随频率改变。

如果输出节点还连接了其他负载，才会出现额外的并联分流路径。

3.2 直流输入#

刚接通直流时，电容开始充电，VoutV_{out}Vout​ 按指数曲线上升。经过足够长时间后：

Vout≈VinV_{out}\approx V_{in}Vout​≈Vin​

也就是说，一阶 RC 低通在直流稳态下允许直流电压出现在输出端。此时电容不再继续充电，理想稳态电流降为 0，串联电阻上的压降也趋近 0。

3.3 高频交流输入#

当输入变化周期远小于 RCRCRC 时，输入已经改变方向，电容电压还没有来得及变化到同样幅度，因此输出变小，并且相对输入产生明显滞后。

图中黑色曲线可视为输入，红色曲线为电容电压。红色输出幅值明显变小，并且峰值出现得更晚，说明输出既有衰减，也有相位滞后。

3.4 低频交流输入#

输入变化较慢时，电容有足够时间跟随输入充放电，所以输出与输入基本重合。

图中红色输出与黑色输入只有很小的幅值和相位差，说明该频率位于低通滤波器的通带内。

3.5 两种解释其实是一回事#

“阻抗分压”和“充放电速度”不是两套互相独立的原理：

  • 阻抗分压适合分析正弦波的稳态幅值与相位；
  • 时间常数适合分析阶跃、方波边沿和启动过程；
  • 两者都由同一组 RRR、CCC 参数决定；
  • 截止频率与时间常数满足 fc=1/(2πτ)f_c=1/(2\pi\tau)fc​=1/(2πτ)。

4. RC 高通滤波器#

4.1 电路结构#

高通滤波器的连接方式是：电容串联在信号路径中，电阻从输出节点接到 GND，输出取电阻两端。

简化拓扑可以写成：

高通滤波器的作用是：

让高频信号基本通过，让低频和直流逐渐衰减。

4.2 用阻抗分压理解#

高通输出取在电阻两端，因此：

VoutVin=RR+ZC=jωRC1+jωRC\frac{V_{out}}{V_{in}} =\frac{R}{R+Z_C} =\frac{j\omega RC}{1+j\omega RC}Vin​Vout​​=R+ZC​R​=1+jωRCjωRC​

幅值比为：

∣VoutVin∣=ωRC1+(ωRC)2\left|\frac{V_{out}}{V_{in}}\right| =\frac{\omega RC}{\sqrt{1+(\omega RC)^2}}​Vin​Vout​​​=1+(ωRC)2​ωRC​

相位为：

φHP=90∘−arctan⁡(ωRC)\varphi_{HP}=90^\circ-\arctan(\omega RC)φHP​=90∘−arctan(ωRC)

低频输入#

低频时 XCX_CXC​ 很大，整个回路电流很小，因此接地电阻上的电压也很小：

Vout=IR≈0V_{out}=IR\approx0Vout​=IR≈0

低频不是“被电阻过滤掉”，而是被串联电容的高容抗阻挡，导致电阻上几乎没有输出。

高频输入#

高频时 XCX_CXC​ 很小，串联电容近似低阻抗连接，大部分输入电压出现在电阻两端：

Vout≈VinV_{out}\approx V_{in}Vout​≈Vin​

4.3 高通对直流和边沿的响应#

直流稳态 f=0f=0f=0 时，串联电容相当于开路，因此高通输出最终回到 0。

但输入刚发生跳变时，电容两端电压不能突变，输出端会先出现一个脉冲，再按时间常数 τ=RC\tau=RCτ=RC 衰减。高通因此还可用于：

  • 去除直流偏置，只保留交流变化；
  • 交流耦合；
  • 检测方波上升沿和下降沿；
  • 将缓慢基线与快速变化分离。

5. 截止频率与 -3dB#

一阶 RC 低通与高通的截止频率相同：

fc=12πRCf_c=\frac{1}{2\pi RC}fc​=2πRC1​

有些资料写作 ftf_tft​，但工程中更常用 fcf_cfc​，其中下标 c 来自 cutoff。

5.1 截止频率处为什么有 XC=RX_C=RXC​=R#

当 f=fcf=f_cf=fc​ 时：

XC=12πfcC=12π⋅12πRC⋅C=RX_C=\frac{1}{2\pi f_cC} =\frac{1}{2\pi\cdot\frac{1}{2\pi RC}\cdot C} =RXC​=2πfc​C1​=2π⋅2πRC1​⋅C1​=R

此时电阻阻值与容抗大小相等，但它们的相位不同：

  • 电阻阻抗是 RRR；
  • 电容阻抗是 −jR-jR−jR；
  • 总阻抗的大小是 R2+R2=2R\sqrt{R^2+R^2}=\sqrt{2}RR2+R2​=2​R，不是 2R2R2R。

所以输出并不是普通直流分压得到的 1/21/21/2。

5.2 截止频率处的幅值#

低通和高通在各自截止频率处都有：

∣VoutVin∣=12≈0.707\left|\frac{V_{out}}{V_{in}}\right| =\frac{1}{\sqrt{2}} \approx0.707​Vin​Vout​​​=2​1​≈0.707

换算成分贝：

20log⁡10(0.707)≈−3.01dB20\log_{10}(0.707)\approx-3.01\text{dB}20log10​(0.707)≈−3.01dB

因此，-3dB 表示：

  • 电压或电流幅值变为通带值的约 70.7%；
  • 对同一负载而言，功率变为通带功率的 50%；
  • 不是电压幅值变为 50%。

5.3 截止频率处的相位#

滤波器f=fcf=f_cf=fc​ 时的幅值f=fcf=f_cf=fc​ 时的相位
RC 低通0.707输出滞后输入 45°
RC 高通0.707输出超前输入 45°

5.4 不要把 -3dB 与正弦波有效值混在一起#

正弦波本身的有效值关系是：

VRMS=Vpeak2V_{RMS}=\frac{V_{peak}}{\sqrt{2}}VRMS​=2​Vpeak​​

滤波器在截止频率处的增益也恰好是 1/21/\sqrt{2}1/2​。两个公式数值相同，但含义不同，不能混为一步计算。

例如，输入正弦波峰值为 1V：

  1. 输入有效值是 1/2=0.7071/\sqrt{2}=0.7071/2​=0.707V；
  2. 截止频率处输出峰值是 1×0.707=0.7071\times0.707=0.7071×0.707=0.707V；
  3. 输出有效值是 0.707/2=0.50.707/\sqrt{2}=0.50.707/2​=0.5V。

6. “高频”和“低频”都是相对截止频率而言#

同一个 1kHz 信号，对不同 RC 电路可能是低频、截止频率附近，也可能是高频。

频率范围RC 低通表现RC 高通表现
f≪fcf\ll f_cf≪fc​基本通过明显衰减
f=fcf=f_cf=fc​幅值 0.707，相位 -45°幅值 0.707，相位 +45°
f≫fcf\gg f_cf≫fc​明显衰减基本通过

一阶 RC 滤波器在截止频率之外的渐近斜率为：

  • 低通阻带：约 -20dB/十倍频程；
  • 高通低频阻带：约 +20dB/十倍频程。

这意味着一阶滤波器的过渡是渐进的，不会在 fcf_cfc​ 处像开关一样突然从“通过”变为“完全不通过”。

9. 工程应用#

9.1 低通滤波器#

  • 传感器输出去除高频噪声；
  • ADC 前端抗混叠滤波；
  • PWM 经过低通后得到平均模拟电压；
  • 按键和慢速数字输入的硬件消抖；
  • 电源采样信号平滑；
  • DAC 或模拟输出的高频镜像抑制。

9.2 高通滤波器#

  • 音频或模拟信号交流耦合；
  • 去除传感器直流偏置；
  • 提取快速变化、冲击和边沿；
  • 衰减低频漂移；
  • 在不需要低频信息时抑制 50Hz/60Hz 工频成分。

> 高通只能按频率衰减低频成分。如果 50Hz/60Hz 工频落在有效信号频带内，高通会同时损伤有效信号。共模干扰也不能简单依靠单端高通解决，应结合差分测量、共模抑制比、接地、屏蔽、共模扼流圈或对称 RC 网络分析。

10. 真实电路中的负载效应#

前面的标准公式默认：

  • 信号源内阻足够小或已经计入 RRR；
  • 低通输出端后级输入阻抗远大于 RRR；
  • 高通的接地电阻代表有效负载；
  • 电容近似理想。

真实电路中需要注意：

10.1 信号源内阻#

信号源内阻会与外加电阻共同参与计算。低通实际等效电阻可能是：

Req=Rsource+RexternalR_{eq}=R_{source}+R_{external}Req​=Rsource​+Rexternal​

10.2 后级输入阻抗#

低通输出接入后级时，后级输入电阻会与电容并联，并改变通带增益和截止频率。高通后级输入电阻则会与设计的接地电阻并联：

Req=R∥RinR_{eq}=R\parallel R_{in}Req​=R∥Rin​

计算 fcf_cfc​ 时应使用电容实际看到的等效电阻。

10.3 电容 ESR、ESL 与容差#

真实电容存在：

  • ESR：造成损耗和额外零极点；
  • ESL：高频下使电容逐渐表现为电感；
  • 容差和温漂：使实际截止频率偏离标称值；
  • MLCC 直流偏压效应：工作电压下有效容量可能下降。

10.4 ADC 驱动能力#

ADC 输入通常含有采样保持电容。RC 低通的串联电阻过大时，采样瞬间可能无法在规定时间内充到目标电压，造成转换误差。应同时满足滤波需求和芯片数据手册规定的源阻抗、采样时间要求。

11. 如何选择 R 和 C#

已知目标截止频率后：

RC=12πfcRC=\frac{1}{2\pi f_c}RC=2πfc​1​

R 与 C 有多种组合，但不能只让乘积相同就认为工程效果完全一样。

R 太大可能带来#

  • 热噪声增大；
  • 对输入偏置电流更敏感；
  • ADC 采样充电时间不足；
  • 更容易受到漏电和 PCB 污染影响。

R 太小可能带来#

  • 加重前级信号源负担；
  • 增大交流电流和功耗；
  • 高通耦合时要求更大的电容。

C 太大可能带来#

  • 体积和成本增加；
  • 启动和充放电时间变长；
  • 信号源在边沿处需要更大瞬时电流；
  • 某些放大器驱动大电容时可能不稳定。

工程上通常先根据前后级允许的阻抗范围选 R，再根据目标 fcf_cfc​ 计算 C，最后选择标准容值并重新计算实际截止频率。

12. 示波器实测方法#

准备函数发生器、示波器以及待测 RC 电路：

  1. 输入固定幅值正弦波，例如 1Vpp；
  2. 示波器 CH1 测 VinV_{in}Vin​，CH2 测 VoutV_{out}Vout​；
  3. 两个探头使用同一电路 GND；
  4. 从 0.1fc0.1f_c0.1fc​、fcf_cfc​、10fc10f_c10fc​ 三个频点开始测量；
  5. 记录输出幅值、输入输出时间差和相位；
  6. 在 fcf_cfc​ 附近确认输出幅值约为通带幅值的 0.707；
  7. 低通应观察到输出逐渐滞后，高通应观察到输出逐渐超前。

相位可以通过时间差估算：

φ=360∘ΔtT\varphi=360^\circ\frac{\Delta t}{T}φ=360∘TΔt​

其中 TTT 是信号周期，Δt\Delta tΔt 是两个波形相同特征点之间的时间差。

> 台式示波器探头地夹通常与保护地相连。不要把地夹接到非地节点，否则可能直接短路电路。测量浮地或高压电路时必须使用合适的差分探头和安全方案。

13. 原笔记中的关键修正#

原有说法更准确的表述
截止点“衰减一半分压”截止点电压幅值为 0.707，功率为一半；电压不是一半
XC=RX_C=RXC​=R，所以像两个电阻串联电容阻抗带有 −j-j−j 相位，总阻抗大小为 2R\sqrt{2}R2​R
0.707 就是正弦波有效值截止增益与峰值/RMS 换算是两件不同的事，只是都出现 1/21/\sqrt{2}1/2​
高频在 R 和 C 中“选择”更低阻值路径简单低通回路中 R、C 流过同一回路电流，输出是电容阻抗分压
高通中低频被电阻过滤低频由串联电容的高容抗阻挡，导致电阻两端输出很小
高频被电容完全短路这是近似表达；真实衰减连续变化，且受 ESR、ESL 和负载影响
用单端高通处理所有共模干扰共模问题需按差分/共模路径专门分析，不能只凭频率判断

14. 一句话总结#

RC 低通与高通使用相同的 R、C 和截止频率公式，区别在于元件位置与输出取样点：输出取电容两端得到低通，输出取电阻两端得到高通；截止频率处两者幅值都是 0.707，但低通相位为 -45°，高通相位为 +45°。
