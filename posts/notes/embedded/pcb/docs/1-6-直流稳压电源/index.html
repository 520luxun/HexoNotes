一、电路整体概述#

这是一款运放驱动NPN调整管的串联负反馈线性直流稳压电源

  • 核心目标：把不稳定的12V输入，转换成精准、稳定的固定低压直流输出
  • 核心器件：LM358运算放大器（误差比较+反馈调节）、2N6487G功率三极管（功率调整管）、1.25V精准基准源、1kΩ+1kΩ分压采样电阻
  • 核心机制：深度电压负反馈，可以用运放「虚短虚断」快速计算稳态值，也可以从运放原始开环特性拆解动态稳压全过程

二、稳态输出电压 精准推导（虚短虚断法）#

运放工作在深度负反馈闭环状态，满足两个黄金结论：

  1. 虚短：同相端电压 = 反相端电压，即 V+=V−V_+ = V_-V+​=V−​ 而同相端直接接基准：V+=Vref=1.25VV_+ = V_{ref}=1.25\mathrm{V}V+​=Vref​=1.25V 因此：V−=1.25V\boldsymbol{V_- = 1.25\mathrm{V}}V−​=1.25V
  2. 虚断：运放输入端几乎无电流，采样电阻R1、R2R_1、R_2R1​、R2​串联电流完全相等
分压公式计算#

反相端电压V−V_-V−​是输出电压VoutV_{out}Vout​经过R1、R2R_1、R_2R1​、R2​分压得到：

V−=Vout×R2R1+R2V_- = V_{out} \times \frac{R_2}{R_1+R_2}V−​=Vout​×R1​+R2​R2​​

代入参数 R1=1kΩ,R2=1kΩR_1=1\mathrm{k}\Omega, R_2=1\mathrm{k}\OmegaR1​=1kΩ,R2​=1kΩ：

1.25=Vout×1k1k+1k=Vout21.25 = V_{out} \times \frac{1\mathrm{k}}{1\mathrm{k}+1\mathrm{k}} = \frac{V_{out}}{2}1.25=Vout​×1k+1k1k​=2Vout​​Vout=2×1.25V=2.5V\boldsymbol{V_{out}=2\times1.25V=2.5V}Vout​=2×1.25V=2.5V

👉 理论稳定输出电压：2.5V

三、动态上电+平衡全过程（本质逻辑拆解）#

也就是课上讲解的、从0到稳定的一步步调节过程，还原电路真实工作逻辑：

  3. 持续拉升、不断修正 输出VoutV_{out}Vout​上升后，分压得到的V−V_-V−​也同步抬升：

  • 运放输出1V → Vout≈0.4VV_{out}≈0.4\mathrm{V}Vout​≈0.4V → V−=0.2VV_-=0.2\mathrm{V}V−​=0.2V，仍小于1.25V → 输出继续拉高

四、核心结论与稳压特点#

  1. 运放控制口诀（核心判定逻辑）

    • V+>V−V_+ > V_-V+​>V−​ → 运放输出升高 → VoutV_{out}Vout​上升
    • V+≤V−V_+ ≤ V_-V+​≤V−​ → 运放输出降低 → VoutV_{out}Vout​下降

  2. 稳压能力 负反馈闭环天生抗干扰：输入12V小幅波动、负载RLR_LRL​大小变化时，电路都会自动实时调整，保证输出电压始终稳定在2.5V

  3. 输出可调逻辑 通用输出公式：

Vout=Vref×(1+R1R2)V_{out}=V_{ref}\times\left(1+\frac{R_1}{R_2}\right)Vout​=Vref​×(1+R2​R1​​)

修改分压电阻R1/R2R_1/R_2R1​/R2​的比例，就可以任意设定需要的稳定输出电压

  1. 元件作用补充

  • 三极管2N6487G：电流放大，弥补运放驱动能力不足，给负载提供大电流

  • 10Ω电阻：三极管基极限流，保护运放输出

  • 10μF电容：输出滤波，降低电压纹波、提升系统稳定度

  • 三极管：

[!note] 三极管工作状态详解 ① 始终工作在放大区

稳压正常工作时，三极管既不完全导通饱和、也不完全截止关断，一直处于线性放大区：

  • 基极微小电压变化，就能精准、线性地控制发射极大电流输出
  • 保证负反馈可以精细、连续地调节电压

② 0.6V 压降不影响最终精度

很多人会担心：三极管固定吃掉 0.6V，会不会让电压不准？

不会！

这个 0.6V 压降完全被包裹在运放的负反馈闭环里，运放会自动多输出 0.6V 来精准补偿，最终输出只由基准 1.25V 和分压电阻决定，和三极管参数几乎无关。

③ 周边小元件配合

  • 基极 10Ω 电阻：限制运放输出电流、防止三极管过流烧毁，同时抑制电路自激振荡
  • 输出 10μF 电容：滤除三极管调节带来的电压纹波，让输出电压更平滑稳定

一、示波器波形直观解读#

先看懂两条关键波形：

  1. 白色平直横线：基准电压 Vref=1.25VV_{ref}=1.25\mathrm{V}Vref​=1.25V（运放同相端电压 V+V_+V+​） 上电瞬间就直接建立、全程几乎无波动，是整个稳压电路的精准电压目标锚点。
  2. 输出电压波形： 上电瞬间电压猛地冲高（过冲，峰值超过3V，远大于目标2.5V） → 随后缓慢回落下降 → 最终稳定锁定在一条平整的2.5V水平直线上。

二、完整上电+稳压动态全过程拆解#

1. 上电初始瞬间#
  • 12V供电接通，1.25V1.25\mathrm{V}1.25V基准电压立刻生效：V+=1.25VV_+=1.25\mathrm{V}V+​=1.25V
  • 此时输出端电容、负载电压都为0，分压采样后运放反相端：V−=0VV_-=0\mathrm{V}V−​=0V
  • 运放输入差值：V+≫V−\boldsymbol{V_+ \gg V_-}V+​≫V−​ 👉 LM358运放开环增益极高（几万~几十万倍），输入端微小压差就会让输出瞬间猛冲到接近电压上限。
2. 三极管全开、电压产生上电过冲#
  • 运放输出极高基极电压，远超三极管VBE=0.6VV_{BE}=0.6\mathrm{V}VBE​=0.6V导通阈值
  • 2N6487G功率三极管瞬间深度完全导通
  • 输出电压被瞬间强行拉高，直接冲过目标2.5V，达到3V以上，形成波形上的尖峰过冲。
3. 负反馈启动、主动纠错回落#
  • 输出电压冲高后，分压电阻采样的反相端电压V−V_-V−​同步快速上升
  • 当V−>1.25VV_- > 1.25\mathrm{V}V−​>1.25V时，运放判定：V+<V−\boldsymbol{V_+ < V_-}V+​<V−​ 👉 运放立刻主动拉低自身输出、降低三极管基极电压
  • 三极管导通程度随之减弱，输出电压从3V峰值开始持续、缓慢回落。
4. 逼近平衡点、收敛稳态#
  • VoutV_{out}Vout​一路下降，采样电压V−V_-V−​也同步跟随下降
  • 当V−V_-V−​无限接近基准1.25V1.25\mathrm{V}1.25V时，运放输入差值趋近于0，输出停止大幅变化。
5. 最终闭环稳定锁定#

深度负反馈建立，运放满足虚短特性：V+=V−=1.25V\boldsymbol{V_+=V_-=1.25\mathrm{V}}V+​=V−​=1.25V 分压电阻为上下对称的10kΩ+10kΩ10\mathrm{kΩ}+10\mathrm{kΩ}10kΩ+10kΩ，分压比例为12\frac{1}{2}21​：

V−=Vout×10kΩ10kΩ+10kΩ=Vout2V_- = V_{out} \times \frac{10\mathrm{kΩ}}{10\mathrm{kΩ}+10\mathrm{kΩ}} = \frac{V_{out}}{2}V−​=Vout​×10kΩ+10kΩ10kΩ​=2Vout​​

代入计算：

Vout=2×1.25V=2.5VV_{out}=2\times1.25\mathrm{V} = \boldsymbol{2.5\mathrm{V}}Vout​=2×1.25V=2.5V

最终输出保持平直恒定，后续任何微小电压波动，都会被负反馈瞬间修正，永久稳定在2.5V。

三、为什么一定会出现上电电压过冲？#

你课上提到的「运放输出太快」是核心原因：

  1. 运放响应过快：LM358压摆率高、开环增益极大，反应极其灵敏，上电一瞬间直接把输出拉过了头。
  2. 输出电容的惯性滞后：输出并联10μF10\mathrm{μF}10μF滤波电容，电容电压不能突变、充放电有延迟；运放动作跑在了反馈、电容的前面，必然超调。
  3. 反馈相位差：分压采样、三极管导通都存在微小物理延迟，控制信号滞后，形成暂态的电压冲高，这是所有闭环负反馈系统的固有暂态特性。
  1. 电路本质：运放+功率三极管搭建的分立元件LDO低压差线性直流稳压电源
  2. 稳压核心逻辑口诀：
    • V+>V−V_+>V_-V+​>V−​ → 运放输出升高 → 三极管导通增强 → 输出电压抬升
    • V+<V−V_+<V_-V+​<V−​ → 运放输出降低 → 三极管导通减弱 → 输出电压回落
  3. 上电完整流程：基准建立→运放猛冲→电压过冲→负反馈纠错回落→动态平衡→稳定2.5V恒压
  4. 过冲是暂态过程，稳态输出精度仅由基准电压和分压电阻比值决定。

进阶扩展#

  1. 减小/消除上电过冲的优化方法
  • 在运放输出与地之间增加小型相位补偿电容，降低运放响应速度
  • 在反馈分压电阻上并联小容量加速电容，补偿反馈延迟
  • 合理搭配输出滤波电容容量，并非越大越好，容量过大反而会加剧过冲、震荡
  1. 负载稳压能力验证 仿真中切换1kΩ重载/10Ω轻载负载，输出电压会瞬间微小波动，随即立刻被反馈拉回2.5V，体现电路优秀的负载调整率
  2. 输出电压任意修改公式 通用稳压公式：
Vout=Vref×(1+R上分压R下分压)V_{out}=V_{ref}\times\left(1+\frac{R_{上分压}}{R_{下分压}}\right)Vout​=Vref​×(1+R下分压​R上分压​​)

修改分压电阻比值，即可自定义任意稳定输出电压。

二、核心稳压原理拆解#

1. 第一步：稳压管钳位基极电压#

稳压二极管的核心特性： 只要给稳压管施加反向电压、达到击穿电压，稳压管就会进入齐纳击穿区，此时哪怕输入电压有小幅波动，稳压管两端的电压会牢牢固定在标称稳压值（5.6V）。

  • 12V输入经过1kΩ电阻R1，给稳压管供电
  • 稳压管反向击穿后，三极管基极对地电压 VBV_BVB​ 被永久钳位在 5.6V
  • R1保证稳压管工作在安全击穿电流区间，不会被烧坏

2. 第二步：三极管射极跟随，输出稳定电压#

这个三极管是NPN管、射极输出组态（射极跟随器），有固定电压规律： 三极管正常导通放大时，发射结正偏，存在固定结压降： VB−VE=VBE≈0.6∼0.7VV_B - V_E = V_{BE} ≈ 0.6\sim0.7VVB​−VE​=VBE​≈0.6∼0.7V 题目中我们取典型值 VBE=0.6VV_{BE}=0.6VVBE​=0.6V

变形得到输出电压公式： VOUT=VE=VB−VBEV_{OUT}=V_E = V_B - V_{BE}VOUT​=VE​=VB​−VBE​

代入基准电压计算： VOUT=5.6V−0.6V=5VV_{OUT}=5.6V - 0.6V = \boldsymbol{5V}VOUT​=5.6V−0.6V=5V

✅ 稳压逻辑闭环： 基极电压被稳压管锁死在5.6V，发射极电压就会自动稳定在5V；哪怕输入12V小幅波动、负载轻微变化，输出都会维持在5V左右，实现直流稳压。

三、致命短板：巨大功耗与极低效率#

这就是线性稳压电源最核心的弊端，也是原讲解重点说明的部分：

1. 三极管的管压降#

三极管串联在12V输入和5V输出之间，集电极接12V、发射极接5V输出： VCE=VC−VE=12V−5V=7VV_{CE} = V_C - V_E = 12V - 5V = \boldsymbol{7V}VCE​=VC​−VE​=12V−5V=7V

2. 功率分配与发热计算#

举例场景： 假设负载等效电阻 RL=5ΩR_L=5ΩRL​=5Ω

  • 负载电流：ILOAD=VOUTRL=5V5Ω=1AI_{LOAD}=\frac{V_{OUT}}{R_L}=\frac{5V}{5Ω}=1AILOAD​=RL​VOUT​​=5Ω5V​=1A
  • 三极管串联在回路中，流过三极管的电流≈负载电流=1A
功率拆分#

  1. 负载有用功率（有效做功）： P有用=VOUT×ILOAD=5V×1A=5WP_{有用}=V_{OUT}×I_{LOAD}=5V×1A=\boldsymbol{5W}P有用​=VOUT​×ILOAD​=5V×1A=5W

  2. 三极管无用损耗（全部变热量）： P管损耗=VCE×IC=7V×1A=7WP_{管损耗}=V_{CE}×I_C=7V×1A=\boldsymbol{7W}P管损耗​=VCE​×IC​=7V×1A=7W

  3. 电源总输出功率： P总=12V×1A=12WP_{总}=12V×1A=12WP总​=12V×1A=12W

3. 效率与发热问题#

  • 电源整体效率：η=5W12W≈41.7%\eta=\frac{5W}{12W}≈\boldsymbol{41.7\%}η=12W5W​≈41.7%，不到一半
  • 超过一半以上的电能，全部被三极管以热量形式浪费
  • 输出电流越大、输入输出压差越大，三极管发热就越恐怖，必须搭配大功率散热片

线性稳压电源的本质： 通过功率三极管主动“吃掉”输入多余的电压，把压差全部转化为热量，来换取输出电压稳定。

四、电路优缺点总结#

✅ 优点#

  1. 元件极少、成本极低、电路简单易制作
  2. 无高频开关、输出纹波极小、电磁干扰极低
  3. 无需复杂控制，即可实现基础稳压

❌ 缺点#

  1. 效率极低、发热严重，大电流场景完全不适用
  2. 稳压精度一般（开环无反馈）
    • 三极管VBEV_{BE}VBE​会随温度变化（温度每升高1℃，VBEV_{BE}VBE​下降2mV），输出电压温漂大
    • 负载电流变化时，输出电压会小幅下跌，负载调整率差
  3. 输入电压不能远高于输出电压，否则损耗会指数级飙升

带反馈和不带反馈的直流稳压电源的区别#

一、最直观的结论#

二者最大、最本质的区别：输出电压的稳定性与抗干扰能力

  • ✅ 带负反馈闭环电路：输出电压极致稳定，负载变化、器件差异、温度变化都几乎不会拉偏输出
  • ❌ 不带反馈开环电路：只能粗略稳压，负载一变、温度一变、器件参数一波动，输出电压就明显偏移目标值

二、仿真现象直观对比#

1. 初始轻载状态#

![](assets/PCB/1-6 直流稳压电源.assets/4.png)　![](assets/PCB/1-6 直流稳压电源.assets/5.png)

  • 带反馈电路：输出精准锁定目标5V，示波器波形平直无偏差
  • 不带反馈电路：标称理论5V，实际输出只有约5.2V 偏差来源：
    1. 稳压管本身存在制造误差（标称5.6V，实际并非精准5.6V）
    2. 三极管导通压降VBEV_{BE}VBE​天生存在个体差异

2. 突加大重载、电流暴涨后#

![](assets/PCB/1-6 直流稳压电源.assets/7.png)

  • 带反馈电路：输出电压牢牢保持5V，几乎纹丝不动
  • 不带反馈电路：输出电压直接下跌，从5.2V掉到5.083V 负载越重、电流越大，电压跌落就会越明显

三、底层原理拆解#

🔴 不带反馈（开环稳压）#

电路逻辑#

稳压管先把三极管基极电压固定死（5.6V），再利用三极管射极跟随特性： Vout=V稳压值−VBEV_{out}=V_{稳压值}-V_{BE}Vout​=V稳压值​−VBE​

致命缺陷#
  1. 三极管VBEV_{BE}VBE​不是固定常数
    • 小电流（5mA轻载）：VBE≈0.5VV_{BE}≈0.5VVBE​≈0.5V
    • 大电流（500mA重载）：VBE≈0.8VV_{BE}≈0.8VVBE​≈0.8V 电流一变，VBEV_{BE}VBE​立刻改变，输出电压必然跟着变
  2. 完全开环、不会纠错 电路就像「瞎子」「躺平的执行者」： 只管把基极定在5.6V，完全不监测、不关心最终输出电压到底是多少，哪怕输出已经严重偏离目标，也不会做任何调整。
  3. 额外误差：温度升高，VBEV_{BE}VBE​还会进一步漂移，电压偏差持续扩大。

🟢 带运放负反馈（闭环稳压）#

核心工作逻辑#

整套系统是眼睛+大脑+执行机构的闭环：

  1. 眼睛（分压电阻）：实时采样当前真实的输出电压
  2. 大脑（LM358运放）：把采样电压和精准基准电压做对比
  3. 执行（功率三极管）：动态调整三极管基极电压，修正输出
突加负载的自动调节全过程#
  1. 稳态轻载：输出稳定5V，运放满足虚短：V+=V−V_+=V_-V+​=V−​，系统平衡
  2. 突然挂大负载：电流瞬间从5mA飙升到500mA，三极管VBEV_{BE}VBE​立刻从0.5V涨到0.8V
  3. 瞬间波动：输出电压短暂下跌到4.5~4.8V
  4. 运放立刻感知偏差：采样电压V−<V_- < V−​<基准电压V+V_+V+​
  5. 主动补偿：运放自动拉高自身输出，抬高三极管基极驱动电压
  6. 重新平衡：运放持续微调，最终抵消VBEV_{BE}VBE​的上涨，把输出精准拉回5V，再次回到稳定状态
神奇特性#

三极管VBEV_{BE}VBE​变化、负载变化、稳压管误差、输入小幅波动，全部被负反馈环路自动补偿、抵消 最终输出电压只由精准基准+分压电阻比值决定，和三极管、器件本身参数几乎无关。

四、形象比喻记住区别#

  • 不带反馈开环： 只设定初始目标，全程不管最终结果，做得好不好、偏没偏离，完全不知道，也不会改正。

  • 带反馈闭环： 时刻盯着最终结果，动态判断：

    • 输出电压太低了 → 主动拉高

    • 输出电压太高了 → 主动拉低

      全程毫秒级实时微调，永远死死锁定设定电压。

五、全维度性能对照表#

对比项目不带反馈（开环稳压）带反馈（闭环负反馈稳压）
控制类型开环无反馈深度电压负反馈闭环
输出电压精度低，天生存在固有误差极高，稳态几乎零偏差
带载/负载稳定性差，重载明显掉压优异，负载变化电压几乎不变
温度稳定性很差，温漂严重极好，温度影响被自动补偿
器件参数影响极大，元件差异直接改变输出极小，器件差异几乎无影响
抗输入电压波动弱强
电路复杂度&成本极简、成本极低稍复杂、成本略高

六、二者共同的天生短板#

两种电路都属于串联线性稳压电源，因此拥有一样的物理局限： 三极管串联在输入和输出之间，输入和输出的电压差全部由三极管承担，转化为热量浪费，整体效率偏低，大压差、大电流下发热严重。

七、场景选型建议#

✅ 选不带反馈开环电路 简易玩具、指示灯、非精密供电、极致压缩成本、小电流场景，粗略稳压即可。

✅ 选带负反馈闭环电路 单片机供电、传感器、精密模拟电路、工业电子产品，需要电压精准、稳定、抗干扰、带负载能力强，是现在主流稳压方案。
